Сурагчийн дугаар (01–50), асуулт, хариултын сонголт, тайлангийн бүтэц, график болон бусад сайтын хэсгийг өөрчлөөгүй.

Шинэ тандалтын хариулт шинэ бүлгийн кодоор хадгалагдана. Хуучин Supabase өгөгдлийг устгахгүй, SQL migration хийхгүй. Тайлан хуучин (6А гэх мэт) болон шинэ (Q7 гэх мэт) хадгалалтын кодыг хоёуланг нь уншиж, хуучин мөрүүдийг ч шинэ кодоор харуулна.

Суулгах:
1. ZIP-ийг задлана.
2. GitHub репозиторын үндсэн хавтас дахь index.html файлыг энэ багцын index.html-ээр солино.
3. Бусад файлд хүрэхгүй.
4. GitHub-д commit/push хийсний дараа сайтын deployment дуусахыг хүлээж, нэг бүлгийн туршилтын хариулт болон тайланг шалгана.

Тайлбар: Энэ багцад зөвхөн эх файлын засвар бэлэн болсон. GitHub-д commit/push эсвэл live deployment хийгдээгүй.
