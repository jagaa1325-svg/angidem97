Файлууд:
1. temperament-support.html — сайтын шинэ тусдаа хуудас.
2. student_temperament_surveys.sql — Supabase-д шинэ хүснэгт, нууцлалын эрх нээх SQL.

Суулгах дараалал:
1. Supabase SQL Editor дээр student_temperament_surveys.sql файлын бүх SQL кодыг нэг удаа ажиллуулна.
2. GitHub repository jagaa1325-svg/angidem97 дээр temperament-support.html нэртэй шинэ файл болгон байршуулна.
3. Үндсэн index.html-ийн <nav> дотор дараах холбоосын товч нэмнэ:
<button onclick="window.location.href='temperament-support.html'">🧠 Темперамент ба хөгжлийн дэмжлэг</button>

Нууцлал ба хэрэглээ:
- Нэр, утас, регистр, хаяг цуглуулахгүй. Ангийн код болон сайн дурын сурагчийн код ашиглана.
- Хүүхэд бөглөхдөө сайн дурын оролцооны нүдийг зөвшөөрч тэмдэглэнэ. Сургуулийн журам, эцэг эх/асран хамгаалагчийн зөвшөөрлийн шаардлагыг дагана.
- 4 сонгодог темпераментын нэршил нь боловсролын өөрийгөө таних дасгалын хүрээнд ашиглагдсан; энэ хуудас нь баталгаажсан психометрийн тест биш, оношлох хэрэгсэл биш.
- Хариултыг зөвхөн эрх бүхий багш дэмжлэг төлөвлөхөд ашиглах ёстой. Үр дүнгээр хүүхдийг шошголох, үнэлэх, ялгаварлахгүй.
